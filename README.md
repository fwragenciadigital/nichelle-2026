# Nichelle Imports · Projeto 2026

Repositório **privado e independente** para implementar componentes personalizados da loja https://www.nichelleimports.com.br/ a partir do projeto https://projetos.fwragenciadigital.com.br/nichelle/2026/index1.html.

> **Regra fundamental:** logo, banner principal, categorias, carrinho, vitrines nativas, produtos, preços, estoque e checkout são administrados pela **Loja Integrada**. O desenvolvimento da FWR acrescenta **somente seções exclusivas** sem duplicar/assumir funcionalidades nativas.

## Começar

O trabalho do Codex acontece na branch `develop`: leia `PROMPT_INICIAL_CODEX.md` e `CODEX.md` quando estiverem disponíveis. A primeira seção exclusiva definida é uma galeria editorial com quatro cards de vídeo vertical, seguindo a imagem enviada no briefing.
