## Regras para o Codex

1. Criar somente Settings realmente utilizados na loja Nichelle; preservar nomes esperados pelo tema compatível.
2. Nunca ativar automaticamente `menuFlutuante`, `feedInstagram` ou recursos que injetam menu/vitrine sem teste de compatibilidade e CLS.
3. Nunca copiar contato, ícone, imagem, token ou código promocional do modelo de outra loja.
4. Se uma variável for nativa da Loja Integrada, preferir o editor nativo em vez de criar gestão paralela.
5. Na fase 1, o runtime `public/nichelle.js` apenas consome a galeria de Shorts; este índice não significa que os 165 Settings já estejam ativos.
